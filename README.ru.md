# AI Memory Vault · Кросс-инструментальное ИИ-хранилище памяти

[English](README.en.md) | [简体中文](README.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Português](README.pt-BR.md) | [Русский](README.ru.md)

> Структура каталогов + свод правил + контрольные скрипты, чтобы **все ИИ-инструменты** — Claude Code, Codex, Cursor, Cline, Gemini CLI, Trae, Qoder, ZCode и другие — использовали **одну общую память**.
> **Ключевая идея: почти нулевая конфигурация — локально ничего не разворачивается.** Вся система — это Markdown-файлы плюс четыре скрипта на чистой стандартной библиотеке Python: скопировать в обычный Markdown-каталог — значит «развернуть». Без зависимостей, без сервисов, без сборки, без плейсхолдеров для замены. Инструменты сами читают корневой `AGENTS.md` и начинают работать; скрипты сами находят хранилище памяти.
>
> **Не привязано к Obsidian**: хранилище памяти — это просто Markdown-каталог (`Memory/`). Подойдёт любой агент, умеющий читать и писать файлы, и любой Markdown-редактор. Автор сам просматривает его в Obsidian — Templater / Dataview это необязательные расширения, а не зависимости.

**Зачем это нужно**: у каждого ИИ-инструмента своя «память» — `~/.claude/`, `~/.codex/`, `.workbuddy/memory/`, принудительные auto-memory… Инструменты не понимают друг друга: смена инструмента — амнезия, а память, спрятанная в приватных форматах, нельзя ни прочитать, ни проверить. Этот проект сводит **единственный источник памяти** в один обычный Markdown-каталог, доступный всем инструментам; в настройках каждого инструмента живёт лишь *указатель + короткий крючок* — это табличка на двери, а не само хранилище.

## Ключевые принципы (кратко, семь)

1. **Почти нулевая конфигурация** — Markdown-файлы + скрипты на чистой стандартной библиотеке; скопировать в каталог — вся установка.
2. **Место у памяти одно** — в настройках инструмента живёт только «указатель + крючок»; само содержимое — никогда.
3. **Структурированные слои** — `Preferences` / `Plans` / `Decisions` / `Lessons` / `Workflows` / `Projects` + `Todo.md`·`Inbox/`·`Archive/`.
4. **Индексы — производные** — их генерирует `mem_index.py` из frontmatter; человек лишь шлифует однострочные описания, и регенерация их не стирает.
5. **Сделано = перемещено** — завершённая задача переносится в `working/completed.md` (с датой) и **удаляется из Todo.md**; никакого ✅ на месте.
6. **Не портятся только те шаги, что под «турникетом»** — за каждым контролем стоит реальный инцидент ([docs/04](docs/04-演化史-门禁背后的事故.md)).
7. **Приватность охраняют стражи, а не совесть** — `.gitignore` + `pre-commit`-хук отклоняет любой коммит, затрагивающий `Memory/`.

## Развёртывание одной фразой

Отправьте этот абзац **дословно любому ИИ-агенту** (Claude Code, Cursor, веб-агенты с доступом к файлам…):

```text
Склонируй (или скачай и распакуй) https://github.com/star-nebula/ai-memory-vault ,
скопируй всё содержимое каталога starter/ в корень моего рабочего пространства памяти —
если у меня уже есть репозиторий заметок, бери его корень, если нет — создай пустой каталог.
Затем выполни в этом каталоге python scripts/mem_index.py --write для генерации индексов.
В конце прочитай корневой AGENTS.md и Memory/_index.md и перескажи мне:
когда ты будешь читать память и как будешь её записывать.
```

## Ручное развёртывание

```bash
cp -r starter/* /путь/к/вашему-хранилищу/   # единственное действие «установки»
```

Ни плейсхолдеров для замены, ни зависимостей для установки. Необязательные шаги:

```bash
python scripts/mem_index.py --write      # генерирует индексы по слоям
python scripts/mem_index.py --check      # турникет: дрейф индексов
python scripts/todo_audit.py --check     # турникет: архивация задач
python scripts/encoding_guard.py <путь>  # турникет: кодировка + управляющие символы
```

**Подключение ИИ-инструментов**: в `starter/Memory/Workflows/AI工具自定义指令.md` лежат полная версия (вставить в «пользовательские инструкции») и минимальная (положить в корневой `AGENTS.md` проекта). По умолчанию пути относительные — работают сразу после вставки.

## Контрольные скрипты

| Скрипт | Что ловит |
|---|---|
| `mem_index.py` | Дрейф ручных индексов · расхождение парных «дословно идентичных» таблиц · отсутствие протокола свежести при чтении |
| `todo_audit.py` | Отмеченные выполненными, но не перенесённые задачи · группы без каталога проекта · ложные заявления «уже перенесено в Todo» · типы вне словаря |
| `encoding_guard.py` | Не UTF-8 / BOM · управляющие символы от «съеденных» ИИ escape-последовательностей (невидимые для grep мины) |
| `sync_memory_instructions.py` | Расхождение между слотами инструкций инструментов и единым источником · загрязнение источника управляющими символами |
