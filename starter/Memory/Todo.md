# Todo（全局总待办）

> 用法：按项目分组，**分组标题一律取 `Projects/` 下的目录名**（归档才有落点）。
> 不用勾选框。**完成 = 移走**：追加到 `Projects/<项目名>/working/completed.md`（带完成日期）**并从本文件删除该条**——不在原地打完成标记（门禁 `todo_audit.py --check` 会拦完成信号残留）。
> 「不再继续」的条目不删：改删除线并在行尾注明日期与原因，留在原分组。

- 示例条目：把本行替换成你的第一条真实待办（写下它时顺手把 `Projects/示例项目/` 改名为真实项目名，并同步改本分组标题）
