# Todo（全局总待办）

> 用法：按项目分组，**分组标题一律取 `Projects/` 下的目录名**（归档才有落点）。
> 不用勾选框。**结案 = 移走**：追加到 `Projects/<项目名>/working/completed/YYYY-QX.md`（带结案日期、结果、原因与来源）**并从本文件删除该条**——不在原地打完成标记（门禁 `todo_audit.py --check` 会拦完成信号残留）。
> 「不再继续」的条目也按结案处理：以「已取消 / 不纳入 / 已终止」等明确结果归档，不在总 Todo 永久保留删除线；历史删除线条目按用户授权范围逐步迁出。
