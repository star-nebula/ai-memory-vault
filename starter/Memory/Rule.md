# 规则（Rule）· 目录页

> 记忆唯一存储地：Obsidian 记忆库 `<VAULT>\Memory`（结构与索引见 `_index.md`）。当前项目名：`<项目名>`。
> **铁律正本在 `AGENTS.md`**（短版钩子正本，常驻各工具系统提示）。本文件 = 按需查阅的路由目录。

## 读取（分层路由）

会话开场三件套：`_index.md`（唯一入口：分层索引 + 读取路由 + 成本约定）+ `Todo.md` + `Projects\<项目名>\_overview.md`，不凭空假设用户偏好或项目约定。**`<项目名>` 的取法**见 `_index.md` §七。**按目的分流的路由表正本在 `_index.md` §二**。

## 操作 → 分节文件映射（读取前据此定范围，禁止无目的通读）

| 操作 | 读哪个文件 |
|---|---|
| 写入 / 登记 / Inbox 审核 | `rule\写入与禁止.md` |
| 会话收尾 / 季度维护 | `rule\收尾与维护.md` |
| 派发子代理 / 改 `scripts\` / 版本与守卫 | `rule\子代理与脚本.md` |
| 大型项目开发（多文件 / 跨会话 / 架构选型） | `rule\vibe-coding.md` |

> 分节文件**沿用节名与条号**——全库「写入第 4 条」「收尾①」等引用不受拆分影响。
> 分发约定：各 AI 工具的 AGENTS.md 只放**短版钩子**（铁律正本），本目录页 + `rule\` 分节是细则权威；需要背景或写入/收尾前，按上表重读对应分节。
