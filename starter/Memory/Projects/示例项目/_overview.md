# 示例项目 · 项目概况

## 项目定位

本目录演示项目层的固定结构：`_overview.md`（本文件，只留定位/关键路径/关联资产/状态四要素）+ `working/` 台账。**接入后把 `示例项目` 改名为你的真实项目**，并同步修改 `Todo.md` 的 `## 示例项目` 分组标题（分组名必须等于项目目录名，`todo_audit.py` 门禁会查）。

## 关键路径

- `working/journal.md`：过程流水（时间倒序，每日一个 `## YYYY-MM-DD` 小节，暂存层）
- `working/completed.md`：已完成条目（「完成 = 移走」的落点）
- `working/plan.md`：计划（需要时创建）
