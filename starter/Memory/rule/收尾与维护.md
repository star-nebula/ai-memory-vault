# 会话收尾 与 定期维护（Rule 分节）

> **会话收尾 / 季度维护时读本文件。**

## 会话收尾（一次性脚本、单轮问答跳过）

> 下列 ①–④ 是**写入动作**；自动钩子即使跑绿，也不等于本会话已完成收尾。

① 待办变更同步到 `Memory/Todo.md`——**本会话已结案事项：追加到对应项目 `working/completed.md`（带结案日期、结果、原因与来源）并从 `Memory/Todo.md` 删除该条**（项目无 `completed.md` 则先建；**两步缺一即视为未收尾**）；过程流水追加到 `working/journal.md` 新日期小节（若项目有工作态）。

② 本会话产生的持久信息落库并登记；journal 中标「候选」的条目按写入规则蒸馏到最终位置，原文留痕；**新建决策笔记当场即合规**——当日写入 `Decisions/` 的笔记必须带 `status` + 「备选方案」节（见 `rule/vibe-coding.md`），不留给次日门检补。

③ 概况变化 → 更新 `_overview.md`。

④ 项目约定文件有变化 → 执行镜像同步（**仅当项目根确有** `AGENTS.md` / `CLAUDE.md`，见 `rule/写入与禁止.md`「写入」第 8 条；项目根无此类文件则不适用）。**记忆库钩子分发链同属本步**：每次收尾跑 `python scripts/sync_memory_instructions.py --check`（真源 ↔ 各工具级指令位逐字比对 + 项目级钩子在位一致 + 入口文件的「当前项目名」不得写回尖括号伪值），不一致退出码 1 → 重新部署而非手工覆写。分发链只有部署没有校验时，坏指针可能在各工具位存活很久无人发现。

## 定期维护（季度）

每季度（YYYY-QX）末做一次参考库瘦身：

1. 审查 `Decisions/` 与 `Lessons/`：将 **>90 天前、已固化/已验证、不再变动** 的条目归档。
2. 归档落点：`Archive/decisions-YYYY-QX.md` 与 `Archive/lessons-YYYY-QX.md`（按分类归并，长论证压缩为「结论 + wikilink 指向原始笔记/相关项目」）。
3. 原位处理：被归档笔记顶部加 `status: archived-YYYY-QX` + wikilink 指向 Archive 条目，保留不死链。
4. **不归档**：仍在进行的活跃决策、未验证的踩坑、近 90 天内、或用户近期仍在引用的条目，留在原位。
5. 触发：无需等季度，当 `Lessons/`（或 `Decisions/`）条目数显著膨胀、检索变慢时随时执行。
6. **自检（每次维护必跑：5 门禁 + 报告项）**：

   - **门禁 ①** 索引 `python scripts/mem_index.py --check`——校验各层 `_index.md` 是否漏行/失效行、**「更新」列滞旧**（实盘与索引不符 → 跑 `--write` 刷新；**「一句话定位 / 关键词」是人工润色值，不自动覆盖**）、工作区根 `_index.md` 与 `Memory/_index.md` 是否漏列顶层项、`Memory/_index.md` 的**「读时时效」节与判据指针**是否在场、**`Decisions/_index.md` 与决策卡是否双向守恒**（每张卡有一行含 `[[Decisions/<文件名>]]`、每个锚命中真实文件）。有漂移则跑 `--write` 修复（**仅生成名单内的层**）。**唯一例外 = `Decisions/_index.md`**：它不进生成名单（`--write --layer Decisions` 退出码 2 明确拒绝），一行可覆盖多个决策；机器只查守恒、不代写内容。**「读时时效」节属手工内容，`--write` 修不了**：改名 / 删除 / 判据指针被抽走一律报红。
   - **门禁 ②** 待办 `python scripts/todo_audit.py --check`——列出 `Todo.md` 里**已带完成标记却未移走**的条目、**分组名与 `Projects/` 目录名对不上**的分组、**journal/plan 里「已并入 Todo」的假声明**，以及 **frontmatter `type` 词表外取值**；有残留退出码 1。合法 `type` 值机读自 `rule/写入与禁止.md` 第 5 条，脚本内不写死第二份；**第 5 条词表解析不出来时退出码 1 而不是静默通过**——失明的门最危险。
   - **门禁 ③** 编码与控制符 `python scripts/encoding_guard.py <记忆库路径>`——非 UTF-8 / BOM 与**权威面裸控制符**（AI 把正文里的 `\a \b \f \r \t \v` 当转义吃掉后留下的 C0/DEL，含不构成 CRLF 的裸 CR；TAB 只认「同行已有正文后紧跟字母/数字」的吞字形态）任一命中退出码 1。转码可 `--fix --backup` 自动做；**控制符只报告不自动改**——被吞的是原文那个字母，须逐处核对原意后手工补回。这类文件还会被 ripgrep 判为二进制 → 对所有基于检索的审计隐形，所以本门是「检索式校验」能成立的前置条件。
   - **门禁 ④** `scope` 词表 `python scripts/todo_audit.py --scope-check`——跨层笔记的 `scope` **非法取值**、`Projects/` 层内或 `_index.md` 上的**冗余出现** → 退出码 1；「跨层缺 `scope`」只提示不拦（补字段是写入侧义务，否则历史旧账会让门恒红）。合法词表由 `Projects/` 实盘目录名 ∪ `global` **实盘推导、脚本内不写死**；改名当天报「非法取值」属预期。
   - **门禁 ⑤** 同名消歧单一正本 `python scripts/mem_index.py --check`——**与门禁 ① 同一脚本、同一次运行**：校验工作区根 `AGENTS.md` 的消歧小节结构完整（五组、三列、无重复），且 `Memory/_index.md` §六 只留指针、指针路径与节名都有效。正本被改名 / 删除 / 塞进代码围栏或注释、索引侧又长出第二份表，一律报红。
   - **报告项 ①** `python scripts/todo_audit.py`——开场读取成本、暂存层体量、`scope` 缺字段、`completed.md` 缺失等。阈值 = `todo_audit.py` 顶部 `LIMIT_*` 策略常量，实测与「待瘦身」清单看报告；**数字不进文档**。
   - **报告项 ②** `python scripts/todo_audit.py` 第十节——**每日 Inbox 审核积压**：`Inbox/` 根下登记日期早于运行当天的文件份数。**只报不拦**：积压可能来自审核任务没跑，也可能来自「审过但块里留有『待本人决定』」；季度只看是否归零与最长滞留天数趋势。
   - **报告项 ③** 暂存层体量——**判压面只收 `journal.md`**；`working/completed.md` 属终态层，只进「最重几份」观测面，不判压。压缩旧段是渐进蒸馏，存量不可能当天清零，故只报告。
