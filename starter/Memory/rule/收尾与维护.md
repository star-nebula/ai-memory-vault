# 会话收尾 与 定期维护（Rule 分节）

> **会话收尾 / 季度维护时读本文件。**

## 会话收尾（一次性脚本、单轮问答跳过）

> 下列 ①–④ 是**写入动作**；自动钩子即使跑绿，也不等于本会话已完成收尾。

① 待办变更同步到 `Memory/Todo.md`——**本会话已结案事项：追加到对应项目 `working/completed/YYYY-QX.md`（带结案日期、结果、原因与来源）并从 `Memory/Todo.md` 删除该条**（项目无当季分片则先建；**两步缺一即视为未收尾**）；过程流水追加到 `working/journal/YYYY-MM.md` 新日期小节（若项目有工作态）。

② 本会话产生的持久信息落库并登记；journal 中标「候选」的条目按写入规则蒸馏到最终位置，原文留痕；**新建决策笔记当场即合规**——当日写入 `Decisions/` 的笔记必须带 `status` + 「备选方案」节（见 `rule/vibe-coding.md`），不留给次日门检补。

③ 概况或当前目标变化 → 更新 `_overview.md` / `_state.md`；`_state.md` 只写当前目标、阻塞、下一步，不追加历史。

④ 项目约定文件有变化 → 执行镜像同步（**仅当项目根确有** `AGENTS.md` / `CLAUDE.md`，见 `rule/写入与禁止.md`「写入」第 8 条；项目根无此类文件则不适用）。**记忆库钩子分发链同属本步**：每次收尾跑 `python scripts/sync_memory_instructions.py --check`（真源 ↔ 各工具级指令位逐字比对 + 项目级钩子在位一致 + 入口文件不得出现尖括号项目名伪值），不一致退出码 1 → 重新部署而非手工覆写。

## 定期维护（季度）

每季度（YYYY-QX）末做一次参考库瘦身：

1. 审查 `Decisions/` 与 `Lessons/`：将 **>90 天前、已固化/已验证、不再变动** 的条目归档。
2. 归档落点：`Archive/decisions-YYYY-QX.md` 与 `Archive/lessons-YYYY-QX.md`（按分类归并，长论证压缩为「结论 + wikilink 指向原始笔记/相关项目」）。
3. 原位处理：被归档笔记顶部加 `status: archived-YYYY-QX` + wikilink 指向 Archive 条目，保留不死链。
4. **不归档**：仍在进行的活跃决策、未验证的踩坑、近 90 天内、或用户近期仍在引用的条目，留在原位。
5. 触发：无需等季度，当 `Lessons/`（或 `Decisions/`）条目数膨胀、检索变慢时随时执行。

### 自检（每次维护必跑：3 门禁 + 1 个季度门禁 + 报告项）

> 门禁与报告项分开编号；不把“报告为绿”误当成“内容已覆盖”。

- **门禁 ①** 待办 `python scripts/todo_audit.py --check`——列出 `Todo.md` 里**已带完成标记却未移走**的条目、**分组名与 `Projects/` 目录名对不上**的分组、**journal/plan 里「已并入 Todo」的假声明**，以及 **frontmatter `type` 词表外取值**；有残留退出码 1。合法 `type` 值机读自 `rule/写入与禁止.md` 第 5 条；第 5 条词表解析不出来时退出码 1，不静默通过。
- **门禁 ②** 编码与控制符 `python scripts/encoding_guard.py <记忆库路径>`——非 UTF-8 / BOM 与**权威面裸控制符**任一命中退出码 1。转码可 `--fix --backup` 自动做；**控制符只报告不自动改**——被吞的是原文那个字母，须逐处核对原意后手工补回。这类文件会被 ripgrep 判为二进制，使后续检索审计失明。
- **门禁 ③** 指令分发 `python scripts/sync_memory_instructions.py --check`——真源与各部署位漂移、真源裸控制符、项目名伪值任一命中退出码 1。
- **季度门禁** `python scripts/todo_audit.py --scope-check`——跨层笔记的 `scope` 非法取值、`Projects/` 层内冗余出现退出码 1；跨层缺 `scope` 只提示不拦。合法词表由 `Projects/` 实盘目录名 ∪ `global` 推导。

- **报告项 ①** `python scripts/todo_audit.py`——启动包成本、overview/state 内容债、暂存层体量、`scope` 缺字段、completed 归档缺失等。阈值 = `todo_audit.py` 顶部 `LIMIT_*` 策略常量；`--cost-check` 只拦 BOOT/实际 assembled，`--content-check` 严格拦内容债；**数字不进文档**。
- **报告项 ②** `python scripts/todo_audit.py` 第十节——**每日 Inbox 审核积压**。只报不拦；季度看是否归零与最长滞留天数趋势。
- **报告项 ③** 暂存层体量——判压面只收 journal 主文件与月分片；completed 归档属终态层，只进观测面，不判压。
- **报告项 ④** `python scripts/state_audit.py`——列出活跃项目缺失、占位、过期（默认 >30 天）或超过 1000 字符的 `_state.md`。只报不拦；加 `--strict` 才在任一状态不可用时退出 1。
