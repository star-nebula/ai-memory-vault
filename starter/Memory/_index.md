# Memory 索引（唯一入口：AI 按此路由，人看地图与审核）

> ⬆ **上级入口**：库根 `AGENTS.md`（工作区总表）。本文件只管记忆库这一面。
> **本文件是记忆库唯一入口**：AI 进来先读这里、再按路径读原文；人看「分层地图」与「审核入口」两节即可。
> 权威执行规则见 `Rule.md`（目录页：操作→分节映射）+ `rule/` 分节文件（写入/收尾前按映射读对应分节）。
> 本页只有「在哪 + 是什么 + 什么词能命中」。**不要在本页找正文**。

## 一、根文件与规则目录

| 文件 | 何时读 |
|---|---|
| `AGENTS.md` | **铁律正本** + 短版钩子（分发到各 AI 工具，常驻系统提示） |
| `Rule.md` | 规则**目录页**：「操作 → 分节文件」映射 + 读取指针；写入或收尾前按映射读对应分节，禁止通读 |
| `rule/` | 规则分节文件：`写入与禁止` / `收尾与维护` / `子代理与脚本` / `vibe-coding` |
| `Todo.md` | 找当前待办（按项目分组） |

## 二、分层地图与路由（6 层 + 3 个根目录）

| 层 | 是什么 | 什么时候读 | 逐篇索引 |
|---|---|---|---|
| `Preferences/` | 个人偏好：语言、代码风格、沟通方式、汇报口径 | 需要用户偏好 / 协作习惯 | `Preferences/_index.md` |
| `Plans/` | 长期规划、目标、路线图 | 需要长期规划与目标 | `Plans/_index.md` |
| `Decisions/` | 决策记录（背景 → 选择 → 备选方案，附日期） | 涉架构 / 技术选型，想知道「为什么这么定」 | `Decisions/_index.md`（专用格式，手工维护） |
| `Lessons/` | 踩坑与解法 | 踩坑 / 排障 / 找已知解法 | `Lessons/_index.md` |
| `Workflows/` | 固定流程手册 / SOP | 要找固定流程 / SOP / 操作手册 | `Workflows/_index.md` |
| `Projects/<项目名>/` | 项目记忆（必含 `_overview.md`；工作态在 `working/`） | 项目记忆、进度、来龙去脉 | `Projects/_index.md` |
| `Todo.md` | **全局总待办**（按项目分组，不用勾选框） | 找当前待办 | ← 本文件 §一 |
| `Inbox/` | 写入登记簿（agent 写完留登记，待审核） | 写入后登记 / 审核对账 | `Inbox/YYYY-MM-DD.md` |
| `Archive/` | 季度归档（`decisions-YYYY-QX.md` / `lessons-YYYY-QX.md`） | 找已归档决策 / 教训 | — |

> **条数不在此表维护**：以各层 `_index.md` 与 `Decisions/_index.md` 页脚为准——本表只管「是什么 / 什么时候读」。

**典型路由**（**本表为正本**）：

- 续开发某项目 → `Projects/<项目名>/_overview.md` + `working/journal.md` 近期 + `Todo.md` 对应分组
- 架构/技术选型 → `Decisions/`（先看其 `_index.md`）
- 排障 / 踩坑 → `Lessons/`
- 用户偏好 / 协作习惯 → `Preferences/`
- 固定流程 / SOP → `Workflows/`

## 三、项目层结构（`Projects/<项目名>/`）

| 文件 | 内容 |
|---|---|
| `_overview.md` | **必读**：项目定位、关键路径、状态、关联笔记 |
| `working/journal.md` | 过程流水（时间倒序，暂存层，收尾时蒸馏） |
| `working/plan.md` | 计划 |
| `working/completed.md` | 已完成（带日期） |

待办**不在这里**——统一在 `Todo.md` 按项目分组。

## 四、Inbox 与 Archive

| 目录 | 说明 |
|---|---|
| `Inbox/YYYY-MM-DD.md` | **写入登记簿**：agent 每次写记忆后追加登记（路径 + 一句话），等审核。同一天追加到同一文件，不散建 |
| `Inbox/Archive/` | 审核结案后的留档（保留日期名） |
| `Archive/` | 季度归档落点（`decisions-YYYY-QX.md`、`lessons-YYYY-QX.md`） |

## 五、审核入口（人的角色）

- **登记审核**：定期审「登记日期早于当天」的日记账——格式合规、落库文件抽验、重复/冲突核对；全部通过即勾选「待审核」并移入 `Inbox/Archive/`。可由定时任务自动执行，人工只看结案记录与挂起事项
- **对自动化结论有异议** → 直接改目标文件，并在当日登记中备注

## 六、同名文件消歧（易混清单）

> 本表与库根 `AGENTS.md` §同名文件消歧 **逐字一致**——两份分别覆盖「AI 从库根进」与「AI 直入记忆库」两条路径。**改一处必须同步另一处。**

| 易混名 | 有两处（或多处） | 该取 |
|---|---|---|
| `AGENTS.md` | 库根 `AGENTS.md`（工作区手册）／`Memory/AGENTS.md`（记忆钩子，分发到各工具） | 看工作区结构/红线 → 库根版；写记忆/收尾 → Memory 版 |
| `Inbox/` | 工作区级 `Inbox/`（闪念捕获，如有）／`Memory/Inbox/`（**记忆登记簿**） | 记忆登记 → `Memory/Inbox/` |
| `Archive/` | `Memory/Archive/`（季度归档）／`Memory/Inbox/Archive/`（登记结案留档） | 记忆归档按用途取：决策/教训归档 → 前者；登记结案 → 后者 |
| `Templates/` | 库根 `Templates/`（**记忆笔记模板在此**）／其他同名目录 | 记忆笔记模板一律取库根 `Templates/` |

## 七、读取成本约定（重要）

- **会话开场最省的动作**：只读三件——本文件 + `Todo.md` + `Projects/<项目名>/_overview.md`；其余按路线下钻，不通读。
- **「当前项目名」怎么拿**（上面第三件的前提）：① 项目根 `AGENTS.md` 里的 `**当前项目名：\`X\`**`（由 `scripts/sync_memory_instructions.py --projects` 生成）→ ② 该文件不存在则从工作目录推断 → ③ 仍推断不出**问用户，不猜**。
- **跨层反查**：五层是平铺共享的，本项目相关的那批只靠 frontmatter 标记 → grep `scope: <项目名>` 与 `scope: global` 两条都要。`Projects\` 层内**不填** `scope`（路径即归属）。
- **grep 本库必须把检索起点放进 `Memory/`**：记忆层被 `.gitignore` 忽略时（隐私边界，不得为了检索去改它），从仓库根起手的检索对整层记忆零命中——**「无匹配」不等于「不存在」**。
- **三件的体量上限**：阈值是 `scripts/todo_audit.py` 顶部的策略常量（`LIMIT_*`），实测与「待瘦身」清单看该脚本报告；数字不进文档（阈值在脚本、实测在报告、文档只指路）。
- **瘦身口径**：`_overview.md` 只留「定位 / 关键路径 / 关联资产 / 状态」四要素，细节下沉 `working/journal.md`、`working/plan.md`。

## 八、维护

- 本文件由结构变化时**手工**更新（低频）；**各层 `_index.md` 中除 `Decisions/_index.md`（专用格式，手工维护）外，均由 `scripts/mem_index.py` 合并生成**：新增笔记自动补行，已有行的人工「一句话」会被保留。
- 防漂移：`python scripts/mem_index.py --check`（有漂移退出码 1，跑 `--write` 修复）。

## 九、读时时效（引用记忆里的断言前，先判它该不该信）

- **记忆是「写下那天为真」的快照，不是现状。** 凡断言关于**路径 / 文件是否存在 / 工具行为 / 环境版本 / 目录结构**，据此动手前先就地复测（`Read` / `Glob` / 一次探针），不要把笔记当成现状本身。
- **免费的时效信号**：各层 `_index.md` 行末「更新」列 = 该篇最后**改动**日期，只证明「动过笔」、不证明「核验过」——别当核验日期用。
- **判据正本（本条只指路，不复述）**：「结论是不存在 / 已落过 / 没问题时，先怀疑给出结论的那次读取」→ `Lessons/批量改写脚本的自检失明.md`。
- **权威级排序**：工具私有记忆位（含 auto-memory 影子层）**不是正本、也不算「已查过」**——查同名与引用一律以记忆库为准。
