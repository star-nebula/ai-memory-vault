# Global hot memory

> 本文件是 Agent 的唯一常驻热层。只放稳定、跨项目、短小的内容；项目状态、流水和长规则不要写在这里。

## 核心偏好

- 默认用中文回答。
- 先给结论，再给依据；涉及文件、路径、工具行为时先复测。
- 用户手改的文件不自动改；改动前逐条确认。
- 记忆只写 `Memory/`，不写工具私有记忆位。

## 工作边界

- 普通任务不默认扫描记忆库。
- 项目任务先运行 `python scripts/memory_boot.py --cwd .`。
- 查历史/原因/踩坑运行 `python scripts/memory_query.py "关键词" --cwd .`。
- 启动不扫全库；只加载有界包，更多背景按需检索。

## 维护

- 热层超过预算时，删除过时内容或把细节移到 `Preferences/` / `Decisions/` / `Lessons/`。
- 新增热记忆必须跨项目稳定，不能是单次任务状态。
